| Playwright Chromium 데스크톱/모바일   | 10개 통과                  |
| Vercel 설정 인스턴스 JSON Schema 검사 | 통과                       |
| Vercel ASGI entrypoint import         | 통과                       |
| 실제 로컬 `/api/health`               | 200, configured=false      |

Vercel 공개 스키마의 자체 메타스키마 검사가 실패하여 `Draft7Validator(schema).iter_errors(config)`로 실제 설정 속성을 검사했습니다. 실제 배포 빌드 성공을 의미하지는 않습니다.

### 핵심 불변 조건

- 존재하지 않는 출처 인용, 실제로 읽지 않은 원문 인용, 원문에 없는 발췌 차단
- 인용 ID/발췌가 유효해도 의미 검증을 통과하지 못한 주장 제거
- 없는 노드 연결·한쪽만 있는 관계 근거·중복 연결 차단
- 동일 도메인의 다른 페이지 보존, 추적 파라미터만 다른 URL 중복 제거
- OpenAI 웹 검색 호출과 재시도 예산 서버 강제, 취소 후 공급자 호출 차단
- 관계 생성 실패/시간 초과 시 카드 보존, 미완료 부문 재시도 표시
- ASGI 연결 종료 시 실행 중 작업 취소와 공급자 클라이언트 종료
- 이전 request_id의 늦은 이벤트 및 중지한 검색 응답이 새 화면에 섞이지 않음
- 샘플 snapshot·가상 데이터가 실제 검색 요청에 포함되지 않음
- 관련 자료 확장 중 기존 위치·viewport 유지, 원문 링크 제공
- IndexedDB 기록·위치 복원/삭제, 기록 열 때 유료 호출 없음
- IME 조합 Enter 전송 차단, 키보드 노드 선택, 모바일 문서 가로 넘침 없음
- 요청 본문 크기, 작업 토큰, 위조 continuation, 빈 질문과 요청 빈도 제한

E2E의 성공·부분 실패 검색은 명시적인 네트워크 테스트 fixture를 사용했습니다. 제품의 live 경로는 이 fixture를 사용하지 않습니다. OpenAI 유료 통합 호출은 실행하지 않았습니다.

## 알려진 제한

1. **실제 공급자 통합 미검증:** 키 설정 후 실제 검색과 구조화 출력, 한국어 품질, 비용/응답 시간을 확인해야 합니다. 기본 모델명은 환경변수로 변경할 수 있습니다.
2. **배포 미실행:** Vercel 프로젝트/자격 증명 연결 없음. Docker CLI는 있지만 데몬이 중지되어 이미지 실행 미검증. 자세한 절차는 DEPLOYMENT.md에 있습니다.
3. **근거 검증은 무오류 보장이 아님:** ID·발췌는 결정적으로 검증하지만 주장 의미와 문서 분류/관계 판단에는 모델 오류가 남을 수 있습니다. 출처와 근거를 UI에 함께 표시합니다.
4. **시간 민감 정보:** 게시일을 추정하지 않고 원문 확인 상태를 구분합니다. 실시간 항공 운임 공급자·예약 연동은 없습니다. 가격·출시일의 최신성은 실제 원문 확인이 필요합니다.
5. **서버리스:** JobStore와 rate limit은 프로세스 단위입니다. 완료 이력은 공용 PostgreSQL, 글로벌 제한은 배포 WAF가 필요합니다. 중지는 이미 접수된 외부 요청의 비용을 취소하지 않습니다.
6. **공용 저장:** 기록은 PostgreSQL에 저장되며 모든 브라우저가 공유합니다. 브라우저 저장소 삭제와 별개로 유지됩니다. 계정/자동 실시간 동기화는 없고 최신 목록은 새로고침으로 조회합니다. 서명 snapshot 7일 만료 후에는 기록 열람은 가능하지만 추가 검색은 새 세션이 필요합니다.
7. **URL 검사:** HTTP(S), 공개 DNS/IP 검증을 통과한 공급자 출처·인용 URL만 등록합니다. 페이지 fetch를 직접 수행하지 않으며 OpenAI 내부 검색/리다이렉트 정책까지 제어하지는 않습니다. AI 인용 요약은 원문으로 취급하지 않습니다.
8. **폰트와 아이콘:** Pretendard는 CDN에서 가져오며 실패 시 시스템 폰트로 표시합니다. 사이트 아이콘은 외부 favicon 요청 대신 일관된 도메인 대체 아이콘을 사용합니다.
9. **선택적 기능:** 보조 개념 노드는 만들지 않으며 검색된 웹페이지가 항상 중심입니다. 관계가 없는 페이지도 독립 카드로 남습니다.
10. **의존성 경고:** pytest 실행 시 Starlette/AnyIO 내부의 deprecation 경고 1개가 있습니다. 테스트 실패는 아닙니다.
