# 파일·이미지 첨부

채팅 바 `+` 메뉴의 파일 첨부·이미지 첨부에서 실제 파일을 선택한다. 업로드 상태와 제거 버튼은 입력창의 첨부 칩에 표시한다. 업로드 중이거나 실패한 첨부가 있으면 전송을 막는다. 첨부만 보내면 기본 질문은 ‘첨부한 자료를 설명해 주세요.’이다.

## 입력과 화면

- 지원: PNG/JPEG/WebP 정지 이미지, PDF, UTF-8 TXT/MD/CSV/JSON. 파일당 기본 3MB, 질문당 4개, 이미지 2천만 픽셀, PDF 20페이지, 텍스트 32,000자. 설정은 backend 환경변수에서 관리한다.
- 전송 즉시 첨부별 `attachment_<UUID>` 소스 노드와 응답 노드를 함께 만든다. 첨부는 응답 위에 배치하며, 두 개씩(좁은 화면은 한 개씩) 배치한다. 기존 노드·viewport는 이동하지 않는다.
- ‘입력 자료’ 연결은 사용자 첨부 관계이며 웹 조회·인용 근거와 구분한다. 첨부를 검증된 웹 출처나 가짜 ToolSource로 만들지 않는다.
- 이미지에는 미리보기, 파일에는 형식 아이콘·이름·크기·PDF 페이지 수를 표시한다. 파일 본문은 카드 안에 표시하지 않는다.
- 카드의 복사·다운로드·펼치기·다음 응답에 사용 액션을 제공한다. 다운로드는 복사 옆 아이콘이며 원본 바이트를 제공한다. 펼치기는 이미지/파일 표시 영역과 파일명을 확장한다.
- 복사는 이미지 픽셀(PNG 클립보드), 텍스트 파일의 전체 내용, PDF의 파일명/다운로드 링크를 복사한다. 브라우저 권한 등으로 실패하면 실패 상태를 표시한다.
- ‘다음 응답에 사용’은 저장된 첨부 ID를 입력창에 다시 추가한다. 다음 요청에서 서버가 해당 원본으로 모델 입력을 구성한다. 재업로드·본문 미리보기 텍스트 대체·소스 노드 복제 없이 같은 자료를 재사용한다.

## 서버와 모델

`POST /api/attachments?filename=...`에 원본 바이너리를 보낸다. JSON 요청 제한은 그대로 유지하고 업로드 경로만 별도 크기 제한을 적용한다. 실제 디코딩과 허용 형식, 크기·픽셀·페이지·문자 수를 검사하며 손상/암호화 PDF, 움직이는 이미지, 비 UTF-8 텍스트는 거절한다. 실패한 내용을 샘플로 대체하지 않는다.

공용 PostgreSQL의 `rabbit_hole_attachments`에 원본, 모델 입력 데이터, 이미지 미리보기, 메타데이터를 저장한다. `make db-init`으로 기존 세션을 보존하면서 테이블을 추가한다. 로컬 디스크·object URL·모델 업체 file ID에 기록 복원을 의존하지 않는다.

`/api/agent.attachment_ids`와 서명 continuation의 턴별 `attachment_ids`에는 ID만 저장한다. 이전 version 2 continuation의 필드 생략은 빈 목록으로 해석한다. 서버가 서명 이력과 현재 질문에 필요한 첨부를 조회한다. 모델 입력 바이너리 합계는 기본 12MB로 제한하며 PostgreSQL에서 바이트를 전송하기 전에 검사한다.

텍스트는 전체 UTF-8 내용을 input_text, 이미지는 방향 보정·긴 변 1536px 이하 JPEG를 input_image, PDF는 원본을 input_file로 전달한다. 첨부 내 지시는 신뢰할 수 없는 자료로 취급하도록 일반 에이전트에 명시한다. 원본 다운로드는 변경 전 파일을 보존한다. 파일 메뉴는 `requested_tool` 강제 웹 도구 선택과 별개이며 함께 사용할 수 있다.

## 기록과 수명

세션에는 첨부 메타데이터·노드 위치·펼침 상태·응답과의 연결만 저장하고 바이너리를 넣지 않는다. `rabbit_hole_attachment_refs`가 세션 참조를 보존한다. 기록 열기는 모델·OCR·재업로드 호출 없이 저장된 미리보기/원본을 사용한다.

전송 전 제거는 미연결·미사용 업로드를 삭제한다. 업로드 취소 이후 늦게 반환된 결과도 정리한다. 응답에 사용된 자료는 초안 제거로 지우지 않는다. 세션 삭제 시 다른 세션 참조가 없는 첨부만 삭제한다. 미연결 업로드는 24시간, 사용됐으나 기록에 연결되지 않은 업로드는 7일 후 만료되며 다음 업로드 때 정리한다. 세션에 연결된 자료는 이 만료 대상에서 제외한다.

## 검증

유료 모델 호출 없이 형식/크기 검증, 잘못된 ID, signed continuation, 멀티모달 입력, 업로드 취소·재시도·원본 재사용, PostgreSQL 재접속/공유 참조/삭제, 데스크톱·모바일 첫 렌더링 및 기록 복원을 검사한다. 실제 모델의 이미지·PDF 이해 품질은 별도 명시적 유료 통합 검증 대상이다.
