# 제품 화면 자료

랜딩 페이지 기능 소개에 사용하는 실제 제품 스크린샷 원본입니다.
원본 PNG는 이 폴더에서 보관하며, 웹용 WebP는 `src/frontend/public/images/landing/`에 있습니다.
파일 이름은 기능을 설명하는 영문 kebab-case로 통일합니다.

웹용 이미지는 원본 비율을 유지하며 최대 2000 × 1600 범위로 축소했습니다.
이미지 경로와 크기는 `src/frontend/src/components/landingImages.ts`에서 관리합니다.
