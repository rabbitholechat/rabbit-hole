# 랜딩 페이지 이미지

사용자가 제공한 `screenshots/`의 실제 제품 화면을 WebP로 최적화한 파일입니다.
원본 비율을 유지하며 최대 2000 × 1600 범위로 축소했습니다.

| 파일 | 원본 화면 |
| --- | --- |
| start.webp | 메인 화면.png |
| answer.webp | 기본 질문 화면.png |
| follow.webp | 이어서 질문하기.png |
| branches.webp | 이어서 질문하기 결과.png |
| tools.webp | 도구 사용.png |
| attach.webp | 이미지 첨부(도구 사용 기능).png |
| image.webp | 이미지 질의.png |
| copy.webp | 복사.png |
| paste.webp | 붙여넣기.png |
| edit.webp | 노드 수정.png |
| connect.webp | 간선 연결.png |
| share.webp | 공유,다운로드.png |
| pdf.webp | PDF 다운로드.png |
