# 시작 화면 손글씨

`nanum-pen-welcome.ttf`는 Google Fonts에서 제공하는 Nanum Pen Script의 시작 문구용 서브셋입니다. 앱에서 외부 폰트 요청 없이 직접 제공합니다.

- 문구: `여기서, 호기심을 이어 보세요`, `작은 궁금함도 좋아요`, `답을 따라, 다음 생각으로`
- 예시 질문: `아이폰 폴더블, 무엇이 달라질까요?`, `gpt-6-astra, 어떤 모델일까요?`, `원티드 AI 챔피언십, 어떻게 참가하나요?`, `이 프로젝트, 어떻게 시작하나요?`
