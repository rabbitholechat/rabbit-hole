# 시작 화면 손글씨

`nanum-pen-welcome.ttf`는 Google Fonts에서 제공하는 Nanum Pen Script의 시작 문구용 서브셋입니다. 앱에서 외부 폰트 요청 없이 직접 제공합니다.

- 문구: `여기서, 호기심을 이어 보세요`, `작은 궁금함도 좋아요`, `답을 따라, 다음 생각으로`
- 출처: https://fonts.google.com/specimen/Nanum+Pen+Script
- 제공 요청: https://fonts.googleapis.com/css2?family=Nanum+Pen+Script&text=%EC%97%AC%EA%B8%B0%EC%84%9C%2C+%ED%98%B8%EA%B8%B0%EC%8B%AC%EC%9D%84+%EC%9D%B4%EC%96%B4+%EB%B3%B4%EC%84%B8%EC%9A%94+%EC%9E%91%EC%9D%80+%EA%B6%81%EA%B8%88%ED%95%A8%EB%8F%84+%EC%A2%8B%EC%95%84%EC%9A%94+%EB%8B%B5%EC%9D%84+%EB%94%B0%EB%9D%BC%2C+%EB%8B%A4%EC%9D%8C+%EC%83%9D%EA%B0%81%EC%9C%BC%EB%A1%9C&display=swap
- 라이선스: [SIL Open Font License 1.1](OFL-NanumPenScript.txt)

문구를 변경할 때는 필요한 글자를 포함하도록 Google Fonts에서 서브셋을 다시 받아야 합니다.
