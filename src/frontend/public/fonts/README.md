# 시작 화면 손글씨

`nanum-pen-welcome.ttf`는 Google Fonts에서 제공하는 Nanum Pen Script의 시작 문구용 서브셋입니다. 앱에서 외부 폰트 요청 없이 직접 제공합니다.

- 문구: `여기서, 호기심을 이어 보세요`
- 출처: https://fonts.google.com/specimen/Nanum+Pen+Script
- 제공 요청: https://fonts.googleapis.com/css2?family=Nanum+Pen+Script&text=여기서%2C%20호기심을%20이어%20보세요&display=swap
- 라이선스: [SIL Open Font License 1.1](OFL-NanumPenScript.txt)

문구를 변경할 때는 필요한 글자를 포함하도록 Google Fonts에서 서브셋을 다시 받아야 합니다.
